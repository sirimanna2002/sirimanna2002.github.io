How I build a project

The same four steps every time.

  1. Clean the dataRemove duplicates, outliers and errors so the model learns from good data.
  2. Train and testCompare models, check the results honestly, including where they are weak.
  3. Build the appWrap the model in an API and a simple web page.
  4. Put it onlineDeploy it and document it on GitHub so anyone can try it.
