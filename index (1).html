Sri Lankan Property Price Predictor

Enter a property's type, location and size and get an estimated price in rupees.

  • Python
  • Random Forest
  • FastAPI
  • Streamlit
  • Cleaned a public Sri Lankan property ads dataset down to 151,687 sale listings (land, houses, apartments).
  • Random Forest model reached R² of 0.81 overall. Houses 0.80, apartments 0.73, land 0.52.
  • Backend API on Railway, web app on Streamlit Community Cloud, code on GitHub.

FairVision: Fairness in Age Prediction

  • PyTorch

  • Built a Streamlit demo using the oversampling model.
